# ツバメクラウド ナレッジベース（デモ文書）

## 会社概要
ツバメクラウドは、オンライン学習プラットフォーム向けに動画ホスティングと
ストリーミング API を提供しています。日本と東南アジアで 130 社の法人顧客に
サービスを提供しています。本社は大阪、データセンターは大阪・東京・シンガポールにあります。

## 料金プラン
- **ライトプラン**：月額 3,500 円。ストレージ 50 GB、月間転送量 500 GB、
  最大 5 ユーザー。メールサポート（48 時間以内に回答）。
- **スタンダードプラン**：月額 19,800 円。ストレージ 1 TB、転送量 5 TB、
  最大 50 ユーザー。優先サポート（4 時間以内に回答）と、動画を自動アップロード
  できる API を利用できます。
- **エンタープライズプラン**：個別見積もり。ストレージ無制限、選択可能な専用
  データセンター、専任の担当者、SLA 99.95%、重大障害には 30 分以内に対応します。

プランの変更は即時に反映され、残りの日数分の差額は日割りで計算されます。

## SLA と信頼性
ライトプランとスタンダードプランの稼働率は 99.9%、エンタープライズプランは
99.95% を保証します。SLA を満たせなかった場合、許容範囲を超えた停止 1 時間ごとに
月額料金の 5% をクレジットとして返還します（1 か月の上限は 100%）。
計画メンテナンスは毎週水曜日の 02:00〜04:00（日本時間）に行い、72 時間前までに
通知した場合は停止時間に含めません。

## セキュリティとコンプライアンス
すべての動画は保存時に AES-256、転送時に TLS 1.3 で暗号化されます。
ツバメクラウドは 2025 年に ISO 27001 認証を取得しました。バックアップは 6 時間ごとに
行い、復元ポイントは 30 日間保管します。お客様がサポートチケットで明示的に許可しない
限り、従業員が動画の内容にアクセスすることはありません。

## 連携
次のイベントの Webhook を利用できます：アップロード完了、トランスコード完了、
動画削除、転送量上限の超過。既成の連携先：Zoom Cloud Recording、Moodle
（LTI 1.3 プラグイン）、Google Classroom、Microsoft Teams。REST API は
OpenAPI 3.0 で文書化されており、スタンダードプランとエンタープライズプランで利用できます。

## API の制限
スタンダードプラン：毎分 600 リクエスト、1 回のアップロードは最大 5 GB
（それ以上はマルチパートアップロード）。エンタープライズプラン：個別に合意し、
通常は毎分 3000 リクエストからです。上限を超えると API は HTTP 429 と Retry-After
ヘッダーを返します。

## 返金ポリシー
初回のお支払いから 14 日以内で、転送量が 10 GB 以下であれば全額返金いたします。
14 日を過ぎると返金はできませんが、下位プランへの変更や、保存済みの動画を失わずに
最長 3 か月の一時停止が可能です。

## よくある質問
1. 「動画の処理に時間がかかる」：10 分間の 1080p 動画のトランスコードには、
   ライトプランとスタンダードプランで平均 4〜6 分、エンタープライズプランでは最短 90 秒かかります。
2. 「字幕を書き出すには？」：字幕は音声認識で自動生成され、「字幕」タブから
   SRT 形式と VTT 形式でダウンロードできます。
