# 青岚云知识库（演示文档）

## 公司简介
青岚云是一家面向在线教育平台的视频托管与直播 API 服务商，服务亚太地区的
180 家企业客户。总部位于杭州，数据中心分布在杭州、新加坡和东京。

## 套餐价格
- **入门版**：每月 199 元。50 GB 存储空间，每月 500 GB 流量，最多 5 个团队席位。
  邮件支持，48 小时内回复。
- **成长版**：每月 999 元。1 TB 存储空间，5 TB 流量，最多 50 个团队席位。
  优先支持，4 小时内回复，可使用 API 自动上传视频。
- **企业版**：价格单独商议。无限存储空间，可自选专属数据中心，配备专属客户经理，
  服务等级协议 99.95%，严重故障 30 分钟内响应。

套餐变更立即生效，计费周期内剩余天数的差价按比例计算。

## 服务等级协议与可靠性
入门版和成长版保证 99.9% 的可用性，企业版保证 99.95%。违反服务等级协议时，
超出允许范围的每小时停机按当月费用的 5% 返还抵扣金，每月最多返还 100%。
计划内维护时间为每周三北京时间 02:00 至 04:00，只要提前至少 72 小时通知客户，
就不计入停机时间。

## 安全与合规
所有视频在存储时使用 AES-256 加密，传输时使用 TLS 1.3 加密。青岚云于 2025 年
通过了 ISO 27001 认证。每 6 小时进行一次备份，恢复点保留 30 天。只有在客户书面
申请时才能访问客户数据，且仅限该客户本人——青岚云员工未经客户通过工单明确授权，
无权访问视频内容。

## 集成
支持以下事件的 Webhook：上传完成、转码完成、视频删除、超出流量限额。现成集成
包括：钉钉、企业微信、飞书以及 Moodle（LTI 1.3 插件）。REST API 采用 OpenAPI 3.0
文档，成长版和企业版客户可以使用。

## API 限额
成长版：每分钟 600 次请求，单次上传请求最大 5 GB（更大的文件使用分片上传）。
企业版：限额单独商定，通常每分钟 3000 次请求起。超出限额时 API 返回 HTTP 429，
并附带 Retry-After 响应头。

## 退款政策
首次付款后 14 天内，如果客户使用的流量不超过 10 GB，可以申请全额退款。
超过 14 天后不再退款，但客户可以降级套餐，或将订阅暂停最多 3 个月，
已存储的视频不会丢失。

## 常见支持问题
1. “视频处理时间太长”——在入门版和成长版上，一段 10 分钟的 1080p 视频平均转码
   时间为 4 到 6 分钟，企业版最快 90 秒（专属转码资源）。
2. “如何导出字幕？”——字幕通过语音识别自动生成，可在视频的“字幕”标签页中
   以 SRT 和 VTT 格式导出。
3. “能否按 IP 或域名限制播放？”——可以。成长版及以上套餐支持设置观众邮箱域名
   白名单和允许播放的国家列表。
